# 求职投递 Skill

让 AI 根据简历自动建立个人资料库、连续填写一批网申，填完统一汇报；你负责登录、审核和最终提交。当前是首个公开版本，招聘网站的适配情况欢迎反馈。

把下面这段指令和你的简历一起发给 AI，填写仓库地址即可：

```text
请帮我配置求职投递 Skill：[填写本仓库地址或本地目录]。我已附上简历；有多份简历时，只询问各自的类别。

先阅读 SKILL.md，使用当前环境支持的方式安装或引用，不覆盖现有同名 Skill，不改动无关文件。检查文件读写、简历读取与 PDF 页面核验、浏览器表单操作及附件上传能力；缺少哪项就说明限制，不假称配置成功。不必为了检查能力访问招聘网站。

按照 Skill，在公开仓库之外建立本地私有资料库，记录简历来源与版本/指纹，核验并保留简历原文、要点标题、顺序和段落，不改写经历。长期通用的补充事实单独保存，未知信息不猜；以后复用资料库，换新版简历时再更新。简历、账号和资料库不得写入公开仓库，不保存密码或验证码。

岗位池与分类规则可选；只有我提供并要求按分类处理时才配置，否则以后按我指定的岗位链接和简历准备申请。只集中询问初始化必需的问题，其余缺项以后填表时补充。

这次只配置，不访问招聘网站，不上传简历，不提交申请。完成后简要告诉我：安装或引用状态、可用能力与限制、资料库位置、未核验或缺失内容，并给我一句发起投递的示例。以后按 Skill 填表并统一汇报缺项，正式提交始终由我完成。
```
